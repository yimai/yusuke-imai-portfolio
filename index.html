Selected Case Study

公共分野の大規模システム刷新プロジェクトにおける文書レビュー支援施策。本人はPMとして技術判断と導入推進を担当しました。

Public Sector × Generative AI Role: Project Manager / Technical Decision Lead

レビュー品質と生産性を両立する、セキュアなAI活用基盤

形式的な指摘に時間を要していた文書レビュー業務を対象に、Azure OpenAI ServiceとAzure AI Document Intelligenceを活用。技術選定から顧客承認、利用定着までを推進しました。

Azure OpenAI Service GPT-4o Azure AI Document Intelligence Prompt Design Secure Azure
Situation

厳格な制約

機密性の高い情報を扱う環境で、レビュー工数の削減と品質の均一化が必要でした。

Decision

非RAGを選択

RAGも検証した上で、参照情報の量・更新頻度・運用負荷を踏まえ、直接コンテキスト入力を採用。

Architecture

解析とレビューを分離

Document IntelligenceでPDF解析を改善し、GPT-4oと観点別プロンプトでレビューを実行。

Leadership

専門家を接続

開発メンバー、Microsoft技術者、Azure専門家、顧客の論点を整理し、承認と展開を推進。

約50%reduction

専用アプリ2種をリリースし、社内成果報告では有識者のレビュー時間を約50％削減。対象グループ全員が少なくとも1回利用する状態まで展開しました。

※ アプリケーションのコーディングは開発メンバーが担当。本人はPMとして、技術提案の評価・採否判断、セキュリティ対応、関係者合意、導入推進を担当。守秘義務に配慮し、案件名・顧客名・構成詳細は一般化しています。
